# MODULE 03 — Carousel Interaction

## Trạng thái

- [ ] Chưa bắt đầu

## Mục tiêu

Người dùng có thể swipe và chọn 1 trong 3 poster ảo.

## Việc cần làm

- [ ] Xử lý `touchstart` / `touchmove` / `touchend`
- [ ] Nhận diện swipe trái/phải
- [ ] Quản lý `selectedPosterIndex`
- [ ] Animation 300ms ease-out
- [ ] Poster giữa được focus
- [ ] Tap poster giữa
- [ ] Mở trang `SongExperience`
- [ ] Truyền đúng `song_id`
- [ ] Test trên điện thoại thật

## Gate 3

```
Scan
→ 3 poster
→ swipe
→ tap
→ mở đúng bài hát
```
